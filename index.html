📋 学习策略

1. 交叉学习法：每天安排2-3个模块交替推进，避免单一模块疲劳。

2. 听课+笔记+练习：每节课后花15分钟整理笔记，再做15-20道对应练习题巩固。

3. 刷题巩固：花生十三刷题8讲安排在理论课结束后集中攻克。

4. 灵活调整：如有特殊情况可前后调整1-2天，但尽量不堆积。

📅 央国企备考时间线（7月 → 11月秋招）

🔰 第一阶段：基础夯实

7月底 — 8月（约4周，与考公并行）

• 利用考公行测课程打基础（判断推理、资料分析、言语理解已覆盖）

• 补充数量关系模块（每天30分钟速算+题型训练）

• 每天积累10个高频成语+5个时政热点

• 周末做1套央国企行测真题摸底

🚀 第二阶段：专项突破

9月（约4周）

• 公基系统学习：政治理论 + 法律 + 经济常识

• 申论写作入门：每周2篇材料分析练习

• 锁定3-5家目标企业，研究其笔试特点

• 每天行测刷题 50 道 + 错题复盘

🎯 第三阶段：冲刺模拟

10月（约4周）

• 目标企业文化突击背诵（考前2-3天过一遍）

• 专业知识查漏补缺（按岗位针对性复习）

• 每周3套全真模拟卷，严格计时

• 英语：每天20分钟阅读保持语感

🏁 第四阶段：秋招实战

11月起

• 网申投递 + 笔试 + 面试同步推进

• 每次笔试后复盘，针对薄弱点补充

• 准备半结构化面试常见问题

• 无领导小组讨论模拟练习

✅ 央国企每日任务（7/29起，与考公并行）

💡 央国企 vs 公务员备考策略

1. 行测是最大公约数：考公的行测课程（判断、资料、言语）完全覆盖央国企行测的核心三模块，一举两得。

2. 差异化补充：央国企额外需要准备公基时政、企业文化和专业知识，利用碎片时间积累即可。

3. 英语不可轻视：若目标包含五大行，英语占比可达40%+，需提前3个月积累词汇。

4. 先广后精：7-8月广撒网打基础，9月锁定目标企业精准发力，10月冲刺。
